Crée un bot Discord permettant de gérer un système complet d’avertissements et de sanctions pour les membres d’un serveur.

Le bot devra inclure les fonctionnalités suivantes :

### 1. Ajouter un avertissement

Créer une commande permettant d’attribuer un avertissement à un membre.

* Seuls les utilisateurs possédant les rôles explicitement autorisés pourront utiliser cette commande.
* Lorsqu’un avertissement est ajouté, un message devra être envoyé dans le salon afin d’informer de la sanction.
* La personne ayant reçu un avertissement devra également être automatiquement informée par message privé.
* Un message détaillé devra également être envoyé dans un salon de logs.
* Les logs devront contenir toutes les informations importantes :

  * Le membre sanctionné ;
  * La personne ayant appliqué la sanction ;
  * La raison de l’avertissement ;
  * La date et l’heure ;
  * L’identifiant ou le numéro de l’avertissement.

### 2. Timeout d’un membre

Créer une commande permettant d’appliquer un **timeout** à un membre pour une durée définie. Ainsi évidement qu'une commande untimeout !

* Seuls les utilisateurs possédant les rôles explicitement autorisés pourront utiliser cette commande.
* La durée du timeout devra être précisée lors de l’exécution de la commande.
* Une raison devra pouvoir être indiquée.
* Lorsqu’un timeout est appliqué, un message devra être envoyé dans le salon afin d’informer de la sanction.
* Le membre sanctionné devra également être automatiquement informé par message privé avec les informations concernant son timeout.
* Un message détaillé devra être envoyé dans le salon de logs.

Les logs du timeout devront contenir :

* Le membre sanctionné ;
* La personne ayant appliqué la sanction ;
* La raison du timeout ;
* La durée du timeout ;
* La date et l’heure de l’application ;
* La date ou l’heure de fin du timeout.

### 3. Consulter l’historique d’un membre

Créer une commande permettant de consulter l’historique complet des sanctions d’un membre.

Cette commande devra afficher toutes les sanctions reçues par le membre, notamment :

* Le nombre total d’avertissements ;
* Le nombre total de timeouts ;
* La liste complète des sanctions ;
* Le type de sanction (avertissement ou timeout) ;
* La raison de chaque sanction ;
* La personne ayant appliqué la sanction ;
* La date et l’heure de chaque sanction ;
* La durée du timeout, lorsqu’il s’agit d’un timeout.

Si le membre ne possède aucune sanction, le bot devra clairement l’indiquer.

### 4. Retirer un avertissement

Créer une commande permettant de retirer un avertissement spécifique d’un membre.

Cette commande devra respecter un système de permissions précis :

* Seules les personnes ou les rôles explicitement autorisés pourront retirer un avertissement ;
* Les autres rôles ne devront pas pouvoir utiliser cette commande, même s’ils disposent d’anciennes permissions similaires ;
* Il doit être possible de retirer un avertissement précis sans supprimer les autres sanctions du membre.

### 5. Système de permissions

Le système de permissions devra être strict et configurable.

Les rôles autorisés devront être définis séparément selon les différentes actions, par exemple :

* Rôles autorisés à mettre un avertissement ;
* Rôles autorisés à mettre un timeout ;
* Rôles autorisés à retirer un avertissement.

Les permissions devront être vérifiées à chaque utilisation des commandes afin d’empêcher tout utilisateur non autorisé d’appliquer ou de retirer une sanction.

### 6. Logs et notifications

Chaque sanction devra être correctement enregistrée et générer les notifications nécessaires.

Pour chaque avertissement ou timeout :

* Un message devra être envoyé dans le salon ;
* Un message privé devra être envoyé au membre sanctionné ;
* Un message détaillé devra être envoyé dans le salon de logs ;
* Toutes les informations devront être enregistrées dans la base de données.

Si le membre a désactivé ses messages privés, le bot devra continuer à appliquer la sanction normalement et enregistrer l’échec de l’envoi du message privé si nécessaire.

### 7. Base de données et persistance

Nous utiliserons **Supabase** pour stocker toutes les sanctions.

La base de données devra enregistrer notamment :

* L’identifiant du membre sanctionné ;
* Le type de sanction ;
* La raison ;
* L’identifiant de la personne ayant appliqué la sanction ;
* La date et l’heure ;
* La durée du timeout si applicable ;
* La date de fin du timeout si applicable ;
* Un identifiant unique pour chaque sanction.

Toutes les sanctions devront rester accessibles dans l’historique du membre, même après un redémarrage du bot.

Le code devra être propre, structuré, sécurisé et facilement maintenable.

### 8. Déploiement

Le bot sera connecté à un repository GitHub qui sera créé ultérieurement.

Le déploiement sera effectué sur **Vercel** !
